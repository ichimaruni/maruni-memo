# maruni-memo

四角・矢印・テキストで、すばやくメモするシンプルなボードです。

## 使う

https://saikai-102.github.io/maruni-memo/

メモは利用中のブラウザの localStorage に保存されます。サーバーへの送信や端末間の同期はありません。ブラウザのサイトデータを削除するとメモも消えます。

## ローカルで開く

`index.html` をブラウザで開くだけで動作します。ビルドや依存パッケージは不要です。

## 更新

`main` ブランチのルートを GitHub Pages で公開しています。`index.html` を変更して push すると反映されます。
