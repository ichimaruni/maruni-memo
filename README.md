# maruni-memo

開いたらすぐ画面全体に書けるメモです。箇条書き・インデントのアウトラインを中心に、ハイライト・赤字と、上に重ねて描く四角・矢印に絞っています。

## 使う

https://ichimaruni.github.io/maruni-memo/

- 行頭で `- ` / `・ ` / `1. ` を打つと箇条書き・番号付きになります。`Tab` / `Shift+Tab`（または `⌘]` / `⌘[`）でインデントします。
- 子項目のある行にマウスを乗せると左に ▾ が出て、押すと子項目をたたみます（黒丸のクリックや `⌘Enter` でも同じです）。たたんだ行は黒丸に輪が付き、「○件」を押すとひらきます。`⌥⇧↑↓` で行を入れ替え、`⌘D` で行を複製します。
- `⌘⇧H` でハイライト、`⌘⇧E` で赤字、`⌘B` で太字にします。
- ツールバーの四角・矢印（`⌥R` / `⌥A`）で、メモの上にフローを描けます。矢印は四角につなぐと一緒に動きます。図形は `⌘D` か `⌥` を押しながらのドラッグで複製できます。
- 図形はほかの四角の端・中心と 8px の格子に吸着し、そろうと赤い線が出ます（`⌘` を押しながらで吸着なし、`Shift` で縦横だけ）。四角の辺・角をドラッグすると大きさを変えられます。
- 空いている所からのドラッグで範囲の図形をまとめて選べます。`Esc` で文字の入力を抜けてから `⌘A` を押すと、図形をすべて選びます。`Shift`+クリックで追加・解除できます。
- `⌘S` で、デスクトップやダウンロードなど好きな場所にファイル（`.json`）として保存します。2回目からは同じファイルに上書きし、`⌘⇧S` で別のファイルに保存します。`⌘O` か、ファイルを画面にドラッグすると開けます（Safari・Firefox では、保存はダウンロードフォルダへのダウンロードになります）。
- ツールバーの「＋」の付いた紙のボタンで、新しいメモにします。今のメモはファイルに上書きしてから閉じます。まだファイルにしていないメモのときは、保存するかを確認します。
- フォルダのボタン（`⌘⇧O`）で、最近保存したり開いたりしたファイルの一覧から切り替えられます。今のメモはファイルに上書きしてから切り替わります。まだファイルにしていないメモのときは、保存するかを確認します。一覧はこのブラウザの IndexedDB に残ります。Chrome・Edge ではファイルそのものを開き直し、Safari・Firefox と、ファイルが見つからないときは、最後に保存・開いた時点の内容を開きます。
- 右下の `?` に操作の一覧があります。

メモは利用中のブラウザの localStorage（`maruni-memo-v2`）に保存されます。サーバーへの送信や端末間の同期はありません。ブラウザのサイトデータを削除するとメモも消えます。以前のボード形式（`yohaku-board-v1`）のデータは、初回に自動で新しい形式に移します。元のデータは残したままです。

## ローカルで開く

`index.html` をブラウザで開くだけで動作します。ビルドや依存パッケージは不要です。

## 更新

`main` ブランチのルートを GitHub Pages で公開しています。`index.html` を変更して push すると反映されます。
